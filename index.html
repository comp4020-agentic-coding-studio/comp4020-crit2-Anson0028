Unity is a real-time 3D game engine.

It renders and simulates your project live, not as pre-rendered frames, so you can build, test and ship interactive 3D and 2D content from one project.

You write it in
C#
Publishes to
25+ platforms

You've probably played something built with it — Hollow Knight: Silksong and Cult of the Lamb both run on Unity.

One project can publish to desktop, mobile, consoles, the web, and headsets like Meta Quest and Apple Vision Pro. See what you can build with it for the full list — and it isn't only games.
